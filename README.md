# liNi Desktop Assistant

liNi is a Windows 11 desktop command panel by Ujan Guin. It combines a desktop-aware glass desklet, AI chat, voice input, web search, and trusted PowerShell skills.

- [Download liNi 3.0 for Windows](https://raw.githubusercontent.com/UjanGuin/ZYLO-SYSTEM-COMMAND-DESKLET/main/windows/downloads/liNi-Setup-Windows-x64.exe)
- [Try the public simulator](https://zylo-desklet.inspiringcondor1.chatgpt.site/)
- [Windows setup and build guide](windows/README.md)
- [Windows 3.0 release notes](windows/RELEASE-NOTES.md)
- [Fedora GNOME legacy package](https://raw.githubusercontent.com/UjanGuin/ZYLO-SYSTEM-COMMAND-DESKLET/v1.0.0/packages/1.0.0/zylo-desktop-assistant-1.0.0-1.fc45.noarch.rpm)

The Windows release is maintained in [windows](windows). The Fedora download is the legacy ZYLO build.
