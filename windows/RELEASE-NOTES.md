# liNi 2.8 for Windows

- **New name and icon.** Start menu shortcuts open **liNi Desktop Assistant** and **liNi Chats**. Updating from ZYLO keeps your settings, keys, chats, skills, and model downloads.
- **Editor's Choice.** The gradient preset in Appearance uses #fb6e11, #f41a49, and #9552fc. The website simulator includes the same palette.
- **Voice.** Spoken replies default to Windows speech and include a second native playback path if the default speech call fails. Pocket TTS is available as an option. Recognition retries on CPU if automatic hardware selection fails.
- **Chats.** Search past conversations, use writing tools, and view Markdown, code, tables, and equations. Set your message bubble color in Appearance.
- **Other Windows updates since 2.5.** Configurable file search depth, close filename suggestions with confirmation, assistant preferences, and improvements to installed app discovery and launch verification.
