# ZYLO Desklet for Windows v2.5

- Add FreeLLMAPI as an optional provider with a unified key and Auto or Fast routing through the local proxy.
- Hide LM Studio and FreeLLMAPI independently in Setup. NVIDIA NIM and Groq stay in the provider switcher.
- Detect Windows user folders, suggest similar filenames, and configure search depth per folder. Videos defaults to level 6.
- Try the saved Groq backup key for retry waits of four seconds or longer.

Use Windows 11 x64 and 64-bit Python 3.11 or newer. Quit a running copy of ZYLO before installing. For FreeLLMAPI, run its proxy on the same PC and add the unified key under Setup → Providers.
