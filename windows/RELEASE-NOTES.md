# ZYLO Desklet for Windows v2.2

- Settings saves immediately. Pasted keys receive a background check, and a verified Groq key starts the app list build when filtering is enabled.
- Exact Windows output volume commands are supported, such as "Set volume to 70%".
- Rolling conversation history keeps the configured number of complete exchanges.
- Installed app and file lookup, visible-window checks for app launches, alternate launchers, and Gemini's browser fallback are included.
- Short Groq rate limits receive automatic retries.
