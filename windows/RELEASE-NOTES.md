# liNi 3.0 for Windows

- Settings and Skills checkboxes have a compact lavender indicator, clearer keyboard focus, and distinct checked and disabled states.
- The website simulator shows Git status and app, file, and volume outcomes directly. The file demo shows the find-file skill and opening status before the result.
- The volume demo accepts up, down, mute, unmute, and exact percentages.

Install on Windows 11 x64 with 64-bit Python 3.11 or newer. Quit the running desklet before upgrading. The upgrade carries over your settings, chats, skills, and voice models.
